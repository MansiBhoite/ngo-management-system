# ngo-management-system
This project is a NGO Management System designed to help non-governmental organizations manage their core operations effectively. It provides features for managing donations, volunteers, events, beneficiaries, and other daily activities of an NGO. The system aims to reduce manual work, increase transparency, and simplify record-keeping.

Key Features:
Add and manage donor and volunteer details
Track donations and generate summaries
Manage events, their schedules, and participants
Store information of beneficiaries and their support history
Admin panel to view, update, and delete data entries
Simple and user-friendly interface

Tech Stack Used:
Frontend: HTML, CSS
Backend: PHP
Database: MySQL (or MySQLi)
Tools: XAMPP/WAMP for local server setup
